# Computer Organization: CPU Design & RISC-V Assembly

## Introduction
Coursework from Computer Organization at Franklin & Marshall College: building a simple CPU in a logic simulator and writing RISC-V assembly programs.

## Contents
| File | Description |
|---|---|
| `hw3-2.circ` | CPU built in Logisim (`homework3_make_a_cpu.pdf` has the specification) |
| `pow-2.S`, `powHardcoded-2.S`, `powRecursive-2.S` | Exponentiation in RISC-V assembly: iterative, hard-coded, and recursive versions using the call stack (`homework4_asm_programming.pdf`) |

## Skills
Digital logic · datapath and control design · RISC-V assembly · calling conventions and recursion at the machine level
